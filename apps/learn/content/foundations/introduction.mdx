In this short course, you'll explore how Savira brings together **Database**, **Auth**, **Storage**, **Edge Functions**, and **Realtime** into a unified developer platform.

By the end, you'll understand how each piece of Savira fits together, how to persist and protect your data, and how to start confidently building your own applications.

## What you'll learn

- **Architecture**: how Savira's core products work together.
- **Data fundamentals**: create tables, insert and retrieve data, and explore our generated APIs.
- **Authentication**: create and sign in users, and make secure requests.
- **Security**: enable Row Level Security (RLS) and write policies to protect your data.
- **Storage**: upload and serve files using buckets.
- **Edge Functions**: run custom backend logic close to your users, using Deno and Savira's serverless runtime.
- **Vector search**: store and query embeddings for AI-powered search and recommendations.

---

## Prerequisites

- A [Savira account](https://supabase.com/) (free)
- Basic familiarity with a terminal to run queries.

---

## Course outline

The course is split into 7 chapters, each approximately 10 minutes long.

1. **What is Savira?**
   Get an overview of Savira's architecture and core products. Create your first project and make a simple API call.
2. **Your First Table**
   Create a Postgres table in Savira, insert data, and query it through the REST API.
3. **Authentication Basics**
   Add users, sign them in, and understand how Savira secures your APIs with JWTs.
4. **Secure Your Data with Row-Level Security**
   Enable Row-Level Security and write policies to ensure users only access their own data.
5. **Storage**
   Store files in Savira Storage and upload and serve files from your buckets.
6. **Edge Functions**
   Deploy simple functions to run backend logic close to your users using Deno.
7. **Vector Search**
   Store and query embeddings for AI-powered search and recommendations using Savira Vector.

---

## Before you begin

Create a new project at [supabase.com](https://supabase.com), open the **Savira Dashboard**, and grab your **API URL** and **anon key** from the [Connect dialog](https://supabase.com/dashboard/project/_/settings/api?showConnect=true&connectTab=frameworks).
You'll use them throughout the course to send real requests to your database and APIs.
